
# HonestDiD Sensitivity Analysis

This directory contains R code for evaluating the sensitivity of estimated effects of residential rooftop photovoltaic (PV) adoption on grid electricity consumption in Cape Town, South Africa, to violations of parallel trends.

## Methodology

The analysis implements the sensitivity framework of Rambachan and Roth (2023), using the `HonestDiD` R package.

Sensitivity intervals are calculated separately for five rooftop PV capacity groups:

- <1 kW
- 1–2 kW
- 2–3 kW
- 3–5 kW
- >5 kW

The analysis uses:

- The relative-magnitudes restriction (`DeltaRM`)
- Conditional least-favorable hybrid confidence intervals (`C-LF`)
- A 95% confidence level
- Sensitivity parameters Mbar = 0, 0.25, 0.5, 0.75, 1, 1.5, and 2
- The average treatment effect over event-study months +6 through +12

The event-study specification includes 11 pre-treatment coefficients (months −12 through −2) and 37 post-treatment coefficients (months 0 through +36). Month −1 is the omitted reference period.

## Script

`HonestDiD_RooftopPV.R`

The script reads previously estimated event-study coefficients and covariance matrices, calculates sensitivity intervals for each PV capacity group, and exports the results to `honestdid_results_reproduced.csv`.

It does not re-estimate the underlying event-study regressions.

## R Dependencies

The analysis was reproduced using:

- R package: `HonestDiD` version 0.2.8

Install the package with:

```r
install.packages("HonestDiD")
```

## Required Inputs

The script expects a directory named `honestdid_inputs_max5` in the R working directory.

For each capacity group, it requires two CSV files:

| Group ID | Capacity | Coefficients | Covariance matrix |
|---|---|---|---|
| 0 | <1 kW | `group_0_betahat.csv` | `group_0_covariance.csv` |
| 1 | 1–2 kW | `group_1_betahat.csv` | `group_1_covariance.csv` |
| 2 | 2–3 kW | `group_2_betahat.csv` | `group_2_covariance.csv` |
| 3 | 3–5 kW | `group_3_betahat.csv` | `group_3_covariance.csv` |
| 4 | >5 kW | `group_4_betahat.csv` | `group_4_covariance.csv` |

Each coefficient CSV contains 48 rows with the following columns:

- `event_time`: Event-study month, ordered from −12 through −2 and 0 through +36
- `att`: Estimated treatment-effect coefficient
- `n_treated_weight`: Aggregation weight information
- `n_cells`: Number of contributing estimation cells

Each covariance CSV contains:

- `event_time`: Event-study month, in the same order as the coefficient file
- 48 additional numeric columns containing the 48 × 48 coefficient covariance matrix

The covariance matrix must use the same coefficient ordering as the corresponding `betahat` file.

These inputs are derived from the event-study estimation and are not generated by this R script. They are not included in the public repository.

## Running the Analysis

From an R session with the required input directory available:

```r
source("04_Robustness/HonestDiD_RooftopPV.R")
```

The script writes `honestdid_results_reproduced.csv` to the current R working directory.

## Confidence Interval Grid

The original reported sensitivity results are reproduced using:

- Lower grid limit: −2
- Upper grid limit: 1
- Grid points: 3,001

Some confidence intervals reach these limits at Mbar = 2. In particular, the upper bounds for the <1 kW, 3–5 kW, and >5 kW groups reach 1, while the lower bound for the >5 kW group reaches −2.

These intervals may extend beyond the specified search grid. Consequently, confidence interval endpoints at the grid boundaries should not be interpreted as fully resolved bounds.

Using a wider grid produces intervals extending beyond these limits.

## Reference
